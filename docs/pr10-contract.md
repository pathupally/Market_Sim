# PR 10 contract: Velorum autonomy release

Status: accepted

Date: 2026-08-01

Base commit: `c3a4aaf`

## Outcome

PR10 turns the inference runtime into a portfolio-facing autonomous-systems
workload. It rebrands the public project as **Velorum** and adds a deterministic
2D radar scenario, grammar-safe vehicle commands, continuous-batch scheduling,
shared-prefix KV accounting, deadline metrics, a JSON trace, and a responsive
browser replay.

The old prediction-market workload remains as a regression target, not the
project's public purpose. Existing `marketforge_*` internal targets remain to
preserve history and avoid a high-risk mechanical namespace rewrite.

## Workload contract

- 32 vehicles and 6 moving tracks over 48 deterministic steps;
- noisy range/bearing radar generated by a fixed xorshift64* stream;
- five finite actions: `HOLD`, `INVESTIGATE`, `INTERCEPT`, `EVADE`, and
  `RETURN`;
- every action round-trips through the generic PR9 token DFA;
- every decision uses the PR8 round-robin scheduler with an eight-sequence
  batch cap;
- every sequence reserves paged KV memory against one immutable 64-token
  shared prefix and releases it on completion;
- the final cache must recover every physical page;
- trace output includes source configuration, radar returns, vehicle/target
  state, action validity, batch generation, latency, and deadline status.

## Measurement semantics

Scheduler latency is a deterministic virtual service-cost model, not a CPU or
GPU wall-clock timing. That makes deadline and fairness regressions exactly
reproducible across machines. The reported faster-than-real-time factor divides
simulated scenario duration by modeled inference service busy time.

CUDA and vLLM performance claims remain anchored to the accepted PR9
source-bound L4 artifact in `docs/pr9-modal-result.json`; PR10 does not change
the accepted CUDA kernels or model backends.

## Acceptance

- Apple Clang Debug and ASan/UBSan builds pass all CTests;
- Linux GCC warnings-as-errors and Clang ASan/UBSan builds pass through the
  bounded Modal CPU portability gate;
- two identical scenario runs compare equal;
- JSON parses and contains 48 frames, 1,536 decisions, and 100% grammar
  validity;
- browser verification passes desktop and mobile layouts, stepping, autoplay,
  asset selection, keyboard access, and a clean console;
- the repository contains a generated reference trace, CI workflow, README,
  and Apache-2.0 license.
